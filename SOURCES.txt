SKYPOD SOURCE CODE

The source distribution for SkyPod Mod and SkyPod Studio is included in the
SkyPod Studio download, Skypod-Studio-1.0.0-win-x64.zip, at:

  Licenses/SkyPod/Skypod-1.0.0-Source.zip

It contains original SkyPod code, matching dependency sources, their original
licenses, and build instructions. Extract it only if you want to inspect,
modify or rebuild the software. It is not needed for normal installation.
The Main Mod and Studio downloads are provided together on the SkyPod files
page; no separate source-code download is required.

Original SkyPod software: GPL-3.0-only. See LICENSE.txt and NOTICE.txt.

The separate FFmpeg encoder retains LGPL-2.1-or-later. Its corresponding
modified source and build script are included in Studio at:

  Licenses/FFmpeg/Skypod-AudioEncoder-8.1.3-Source.tar.xz

Third-party libraries retain their original licenses and attribution.
