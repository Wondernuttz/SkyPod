SKYPOD 1.0.0 - MAIN MOD
======================

This is the in-game part of SkyPod. Install it with your mod manager.
The separate SkyPod Studio download creates soundtracks and location assignments.
No songs are included in either download.

REQUIREMENTS
Skyrim VR, SKSEVR, VR Address Library for SKSEVR, PrismaUI VR, SkyUI VR
and MCM Helper VR.
Install the versions intended for Skyrim VR and follow their installation steps.

VORTEX
1. Install this ZIP in Vortex and enable SkyPod.
2. Enable Skypod.esp in the Plugins tab.
3. Deploy your mods, then start Skyrim VR through SKSEVR.

MOD ORGANIZER 2
1. Install this ZIP as a mod and enable SkyPod in the left pane.
2. Enable Skypod.esp in the Plugins tab.
3. Start Skyrim VR through SKSEVR using that MO2 profile.

This archive has the correct Data folder layout. Do not add another Data folder.

Press F8 to open SkyPod in game. You can change the key in its MCM settings.

ADDING YOUR OWN MUSIC
Download SkyPod Studio separately and extract the whole Studio archive to a
normal tools folder outside the game and your mod manager's mods/staging folder.
Download the Windows x64 Studio package. Read README.txt inside Studio for
the setup steps. Studio includes its audio encoder. Extract the complete Studio archive before importing songs.
Do not install the Studio archive as a game mod.

Install your generated soundtrack output alongside the main mod. Let the output
win file conflicts with the main mod and the music mods used to build it. Keep
Skypod.esp enabled and use only one generated output. Deploy again in Vortex.
Players using a finished soundtrack pack do not need Studio or its encoders.
