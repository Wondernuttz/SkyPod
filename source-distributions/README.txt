SkyPod 1.0.0 corresponding source

Skypod-1.0.0-Source.zip contains original SkyPod source under SkyPod/ and
matching managed/native dependency source under third-party/. Extract it
into a working directory and follow SkyPod/BUILD-SOURCE.txt.

Skypod-AudioEncoder-8.1.3-Source.tar.xz contains the separately licensed,
modified FFmpeg encoder source, change patch, notices and build script.
Extract it and follow its README and Build-Encoder.sh instructions.

Both source archives are also supplied inside the Studio download. Original
SkyPod code is GPL-3.0-only. Third-party components retain their own terms;
the separate FFmpeg encoder remains LGPL-2.1-or-later.
